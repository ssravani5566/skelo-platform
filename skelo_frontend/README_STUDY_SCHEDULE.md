# SKelo Study Schedule frontend update

1. Extract this project and open the `skelo_frontend` folder.
2. Run `npm install` if dependencies are not installed.
3. Set `VITE_API_BASE_URL` in your existing `.env` as before (for example `/api`).
4. Run `npm run dev`.

The new student route is `/schedule`. The sidebar contains **Study Schedule** and the Overview dashboard shows the active plan progress when one exists. No unrelated page styles or features were intentionally changed.

See the backend `STUDY_SCHEDULE_SETUP.md` for migration and reminder scheduler instructions.
